## 1. Request Context & Correlation Architecture

Every inbound HTTP request, Celery worker task, and outbound AI completion carries a unified correlation context:

```text
HTTP Request
  ├── X-Request-ID:       UUIDv4 (Generated by edge proxy or middleware)
  ├── X-Correlation-ID:   Trace identifier propagated across async boundaries
  ├── X-Organization-ID:  Canonical tenant UUID
  └── X-Actor-ID:         Authenticated User/Broker UUID
```

### 1.1 Logging Contract
Logs are output as structured JSON. Under no circumstances may logs include:
- Passwords or hash digests
- API keys, JWT access tokens, refresh tokens
- Raw payment card numbers or Razorpay webhook secrets
- Unredacted customer Aadhaar, PAN, or passport details

Example structured log entry:
```json
{
  "timestamp": "2026-09-25T11:45:00.123Z",
  "level": "INFO",
  "logger": "wefylabs.properties.service",
  "request_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "organization_id": "52c4cbaa-20b6-4e1d-8858-45a72684a055",
  "actor_id": "a1bcec68-3fc4-4cde-9030-1deb7fdab38f",
  "action": "property.create",
  "property_id": "a296ebc9-1b91-40f7-a9bd-54b0804cc682",
  "duration_ms": 42.5
}
```

## 2. AI Observability & Unit Economics (Prompt §42)

Every generative completion routed through `AIGateway` produces a persistent database audit record in `ai_request_records`:

```sql
CREATE TABLE ai_request_records (
    id UUID PRIMARY KEY,
    organization_id UUID NOT NULL REFERENCES organizations(id) ON DELETE CASCADE,
    actor_id VARCHAR(36),
    feature VARCHAR(100) NOT NULL,
    task_type VARCHAR(80) NOT NULL DEFAULT 'completion',
    model VARCHAR(120) NOT NULL,
    provider VARCHAR(50) NOT NULL,
    prompt_version VARCHAR(50),
    input_tokens INTEGER NOT NULL DEFAULT 0,
    output_tokens INTEGER NOT NULL DEFAULT 0,
    latency_ms INTEGER NOT NULL DEFAULT 0,
    cost FLOAT NOT NULL DEFAULT 0.0,
    status VARCHAR(40) NOT NULL DEFAULT 'FAILED',
    error_code VARCHAR(80),
    retrieval_count INTEGER NOT NULL DEFAULT 0,
    tool_count INTEGER NOT NULL DEFAULT 0,
    human_override BOOLEAN NOT NULL DEFAULT FALSE,
    request_id VARCHAR(64),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() NOT NULL
);
```

### Telemetry Capabilities
1. **Per-Tenant Unit Economics**: Calculate total LLM spend per customer organization per billing cycle.
2. **Model Performance Monitoring**: Track token counts, average latency, and provider error rates by model.
3. **Auditing AI-Assisted Actions**: Correlate lead qualification recommendations and site visit bookings with their originating model prompt version.

## 3. Outbox Queue Metrics & Health Diagnostics

The `/health/deep` endpoint tracks the state of the transactional outbox:

```json
{
  "outbox_queue": {
    "pending": 3,
    "failed": 0,
    "dead_letter": 0
  },
  "dependencies": {
    "database": {
      "status": "ok",
      "latency_ms": 1.25,
      "migration_head": "0035_canonical_tenant_foundation"
    },
    "redis": {
      "status": "ok",
      "latency_ms": 0.85
    }
  },
  "security_metrics": {
    "active_threats_blocked": 142,
    "rate_limit_hits_last_hour": 5
  }
}
```

Alert thresholds:
- `outbox_queue.pending > 500`: Warning (Worker queue backlog).
- `outbox_queue.dead_letter > 0`: Critical alert (Requires manual operator inspection).
- `database.latency_ms > 200`: Degraded query performance alert.
