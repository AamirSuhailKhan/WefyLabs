# WefyLabs Phase 1 Sprint 1D — Future Product Backlog

**Purpose**: Captures deferred out-of-scope opportunities discovered during Phase 1 Sprint 1D to protect delivery focus and prevent feature sprawl.

---

## Deferred Items

1. **Multi-Currency Dynamic FX Conversion Engine**:
   - *Description*: Automatic real-time currency conversion (e.g. AED, USD, EUR, INR, GBP) using daily central bank exchange rates for global buyer transactions.
   - *Target Phase*: Phase 2 (Global Expansion).

2. **Real-Time WebSocket Deal Room Bidding**:
   - *Description*: Live bidirectional WebSocket streaming for synchronized multi-agent offer negotiation and real-time counter-bidding in digital deal rooms.
   - *Target Phase*: Phase 2.

3. **Native Mobile Push Notification Daemon**:
   - *Description*: Dedicated Apple APNs and Firebase Cloud Messaging worker for sub-second SLA breach mobile alerts to field sales agents.
   - *Target Phase*: Phase 2.

4. **Predictive Deep Learning LTV & Propensity Model**:
   - *Description*: Machine-learning based buyer propensity scoring replacing the deterministic heuristic aggregation currently used in `revenue_intelligence`.
   - *Target Phase*: Phase 3.

5. **3D Interactive Matterport / VR Viewer in Lead Drawer**:
   - *Description*: Embedded 3D virtual tour player directly inside the AI Match and Site Visit panels.
   - *Target Phase*: Phase 3.
